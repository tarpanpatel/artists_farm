Artists Farm Multi-Tenant System

🚀 How to Test Multi-Tenancy

The system now supports multiple properties (Jaipur, Goa) with automatic data isolation.

Option 1: Subdirectory URLs (Recommended)

Default (Jaipur) Goa Property Jaipur Property

.htaccess rewrites these to add ?property_slug= parameter.

Option 2: Query Parameter

?property_slug=jaipur ?property_slug=goa

Option 3: Subdomain (for production)

In production, use subdomains:

  • artistsfarmjaipur.com → Jaipur property
  • goa.artistsfarmjaipur.com → Goa property
  • jaipur.artistsfarmjaipur.com → Jaipur property

🔧 Technical Implementation

Database Changes:

  • Added properties table with default Jaipur/Goa properties
  • Added property_id column to all data tables
  • All API queries now filter by property_id

Property Detection Logic (property_resolver.php):

  1. Priority 1: URL path segment (e.g., /goa/api/router.php)
  2. Priority 2: Query parameter (?property_slug=goa)
  3. Priority 3: HTTP header (X-PROPERTY-SLUG: goa)
  4. Priority 4: Subdomain detection
  5. Priority 5: Default to 'jaipur'
